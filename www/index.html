Interacción Humano-Computador (ISWD723)

La materia da una introducción al campo de la interacción humano-computadora (HCI), un campo interdisciplinario que integra la psicología cognitiva, el diseño, la informática y otros.

Mas información

Base de datos distribuidas (ISWD553)

La materia brinda los conceptos para el diseño e implementación de una base de datos distribuida para una aplicación específica.

Mas información

Data Mining y Machine Learning (ISWD613)

La materia comprende el estudio, análisis y desarrollo de modelos matemáticos y algoritmos computacionales capaces de aprender y a través de ello mejorar su capacidad predictiva con la experiencia (datos), de manera automática.

Mas información

Redes de computadores II (ICCD563)

La materia brinda el conocimiento suficiente que les permita a los estudiantes dimensionar y diseñar redes de datos para la integración de soluciones informáticas avanzadas basadas en la convergencia de servicios.
