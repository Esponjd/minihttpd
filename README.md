# MiniHTTPd

Es un servidor HTTP/1.1	básico desarrollado sin bibliotecas externas a linux.

## El servidor deberá:

- Servir archivos estáticos
- Procesar el método GET y analizar los encabezados básicos de HTTP/1.1
- Admitir múltiples clientes con epoll y conexiones persistentes
- Responder a errores
- Implementar tipos MIME
- Evitar vulnerabilidades comunes
